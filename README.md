# MR//ROOM

MR//ROOM 是 Mineradio 原版播放器界面的响应式网页版本。默认首页直接载入原版星空舞台、播放动态效果、左右侧边栏、顶部搜索与底部控制台，并加入可信局域网内的多设备同步：同一曲目、音质、播放/暂停、进度和应用内音量。此前的 React 改编界面保留在 `/modern` 作为备用入口。

原版的登录、每日推荐、推荐歌曲和搜索入口继续连接本机运行的网易云兼容适配服务；酷狗扫码登录和云歌单通过独立的受限适配器恢复。局域网同步房间作为一套同材质的新入口加入，与账号凭证边界分开。

> 这是基于上游 GPL 项目的非官方网页改编，继续保留原仓库的作者署名、版权与许可文件、原版界面所需视觉资源及作者支持页；不捆绑账号 Cookie/令牌或第三方专辑内容。第三方接口可用性、会员与版权限制由音乐平台决定；请只播放和分享你有权使用的音频。

## 快速启动

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev:lan
```

启动后：

- 主机打开 `http://localhost:3000`。
- 同一局域网的其他设备打开 `http://主机IP:3000`。
- 主机创建房间并复制链接；首台设备是主控，其余设备自动跟随。
- 每台手机/平板第一次收到播放命令时，需要点一次“启用声音并追赶”，这是浏览器的自动播放限制。

Windows PowerShell 若阻止 `npm.ps1`，可使用 `npm.cmd run dev:lan`。

也可以直接双击桌面的 `启动-MR-ROOM局域网.cmd`。启动窗口会列出当前局域网 IP、网页端口 `3000`、同步端口 `8787` 和音乐接口端口 `8790`，并使用 Windows 兼容的实时服务同时启动网站、同步中继和受限音乐适配器，无需预先构建。

## 第三方音乐接口

- 搜索、每日推荐与推荐歌曲保持使用网易云兼容接口；登录面板支持网易云和酷狗扫码登录，“我的歌单”读取已登录酷狗账号的云歌单。酷狗沿用原仓库的二维码登录协议，扫码成功后会额外刷新完整 VIP/SVIP 资料，避免只凭二维码简略响应误判会员等级。
- 网易云 Cookie 和酷狗令牌只保存在系统本机状态目录（Windows 为 `%LOCALAPPDATA%\Mineradio\accounts`），不会返回浏览器、写入 localStorage、进入 WebSocket 房间状态或随 OneDrive 同步。
- 在线播放支持超清母带、高清臻音、无损 SQ、极高 HQ 和标准五档偏好；实际可用档位由平台、账号、会员、单曲所提供的文件和浏览器格式支持共同决定。缺少目标档位时会逐级回退，并显示服务端实际解析到的档位，而不是错误地把酷狗套用网易云会员限制。
- 浏览器只接收规范的网易云数字 ID 或服务端生成的酷狗短期播放标识；没有任意 URL 代理接口，并会拒绝跳转到本机或私网地址。
- “原声、自动·轻微、低频律动、人声清晰、夜间柔和”是本机 Web Audio 预设，不是音乐平台官方音效，也不会同步到其他设备。
- 若接口停止，仍可继续导入本地音乐并使用局域网同步。

## 同步模型

- 本地 Node 中继监听 `0.0.0.0:8787`，以 WebSocket 广播权威播放状态。
- 主控上传所选音频到本机 `.mineradio-lan/tracks`，所有设备通过 Range 请求读取同一文件。
- 在线歌曲在房间状态中只保存受限的 `provider + playKey + quality` 描述，由 `8787` 中继通过本机 `8790` 受限代理转发 Range 音频；真实第三方地址和账号凭证不会广播到设备。
- 客户端以 ping/pong 估算时钟偏移；80–280ms 漂移通过短时 `playbackRate` 微调，更大漂移直接校准。
- 主控离开后，新主控会自动选举并暂停房间，避免双主控竞争。
- 同步的是网页播放器内音量，无法修改设备的物理/系统音量。

自用可信局域网模式默认不加房间 PIN 或设备审批。请勿把 `8787` 或 `8790` 端口直接映射到公网。

## 命令

```bash
npm run dev       # 只启动网站
npm run relay     # 只启动局域网中继
npm run music     # 只启动第三方音乐适配服务
npm run dev:lan   # 网站 + 中继
npm run start:lan # Windows 兼容模式，启动网站 + 中继 + 音乐适配服务
npm run build     # 生产构建
npm test          # 构建、SSR 与中继协议测试
npm run lint      # ESLint
```
